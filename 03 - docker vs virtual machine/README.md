# Docker vs Virtual Machine

## operation systems
### OS Kernel
- core of every OS
- interacts between hardware and software components

### OS Applications Layer
- Applications run on Kernel (i.e. debian, ubuntu)

## docker
- virtualizes the OS applications layer
- services and apps installed on top of that layer
- small size (MB)
- fast startup
- compability on docker

## virtual machine
- virtualizes the complete OS 
- with both layers
- boots up own kernel
- large size (GB)
- long startup
- compability all OS

## docker desktop
- hypervisor layer with a lightweight linux distro
